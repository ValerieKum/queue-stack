# Queue and Stack

The two core data structures side by side: a queue (first in, first out) and a stack (last in, first out).

Part of my portfolio of small, from-scratch visualisations of computer-science ideas. Built on numpy and matplotlib, so every moving part is visible.

## Setup

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
```

## Run

```bash
python queue_stack.py                  # live animated window
python queue_stack.py --save out.gif   # export a looping GIF
python queue_stack.py --save out.mp4   # smaller file, best for the web (needs ffmpeg)
```
